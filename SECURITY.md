# Security Policy

## Supported Versions
Neue Versionen finden Sie in unseren [Releases](https://github.com/Gula1507/checkGPT/releases)

| Version | Supported          |
| ------- | ------------------ |
| >1.0.0   | :white_check_mark: |
| <1.x.x  | :x:                |

## Reporting a Vulnerability
