# CheckGPT - Prometheus
Wir sind Prometheus.
Für umweltbewusste KI-Nutzer:innen soll unser Browser-Plugin eine fundierte und persönlich nachvoll-ziehbare Einschätzung des ökologischen Impacts der privaten KI-Nutzung anzeigen​

## Getting Started
Um das Browser Add-On nutzen zu können, müssen Sie unsere Erweiterung vorerst installieren:

1. Laden Sie sich die Erweiteung von unserem GitHub herunter.
<img width="403" height="351" alt="grafik" src="https://github.com/user-attachments/assets/6472d85e-eb0a-4026-9bbe-1b416a496d01" />

2. Entpacken Sie die heruntergeladene zip-Datei.

4. Navigieren Sie zu den Erweiterungen Ihres Browsers. (z.B. Chrome)
<img width="602" height="444" alt="grafik" src="https://github.com/user-attachments/assets/5b5c554f-b891-4227-80bd-1ee2dc4450a5" />

6. In den Erweiterungen aktivieren Sie den Entwicklermodus und wählen die Schaltfläche "Entpackte Erweiterung laden".
<img width="1921" height="536" alt="grafik" src="https://github.com/user-attachments/assets/fa6fab24-6953-41a2-949f-12250464aaf9" />

7. Wählen Sie den vorher entpackten Ordner aus und klicken auf "Ordner auswählen". Das Add-On wurde nun installiert.

8. Damit das Add-On auch beim normalen Gebrauch sichtbar ist, aktivieren Sie die Funtionen "An Symbolleiste anpinnen" in den Details des Add-Ons.
<img width="417" height="418" alt="grafik" src="https://github.com/user-attachments/assets/cc0870bf-5d5c-40f1-9762-ed40742940a2" />

Sobald es ein entsprechendes Release gibt, wird das Add-On auch im Erweiterungs-Store verfügbar sein.
